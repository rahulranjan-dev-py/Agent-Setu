## एजेंट सेतु (Agent Setu) 1.1.2 — ऐप के अंदर से अपडेट, रिकवरी कोड सुधार

**क्या बदला**
- **ऐप के अंदर अपडेट:** नया वर्शन मिलने पर "डाउनलोड" अब फ़ाइल ऐप में ही डाउनलोड करता है, प्रकाशित चेकसम से जाँचता है और इंस्टॉलर खोलता है। पहली बार Android एजेंट सेतु से इंस्टॉल की अनुमति माँगेगा। (इस वर्शन को अभी की तरह पेज से इंस्टॉल करें; अगली बार से ऐप के अंदर।)
- **सुधार:** पहली बार PIN बनाते समय रिकवरी कोड अब दिखता है। अगर आपने 1.1.1 पर PIN बनाया था, तो सेटिंग्स → ऐप लॉक में PIN एक बार बदलें ताकि कोड मिल जाए।
- 1.1.1 के ऊपर सीधे इंस्टॉल करें; आपका डेटा बना रहेगा।

**इंस्टॉल कैसे करें**
1. नीचे **Assets** में `AgentSetu-v1.1.2.apk` डाउनलोड करें।
2. "अनजान ऐप इंस्टॉल करने" की अनुमति दें; Play Protect चेतावनी आए तो "Install anyway"।
3. ऐप में **सेटिंग्स → ऐप के बारे में** जाकर साइनिंग फ़िंगरप्रिंट नीचे दी गई फ़िंगरप्रिंट से मिलाएँ।

## Agent Setu 1.1.2 — in-app update, recovery-code fix

**What changed**
- **Update inside the app:** when a new version is found, Download now fetches the file inside the app, checks it against the published checksum and opens the installer. Android asks once to allow installs from Agent Setu. (Install this version from the page as before; from the next one, inside the app.)
- **Fix:** the recovery code now appears when you set a PIN for the first time. If you set your PIN on 1.1.1, change it once in Settings → App lock to get a code.
- Install over 1.1.1; your data stays.

**Check your copy**

| | |
|---|---|
| File | `AgentSetu-v1.1.2.apk` |
| SHA-256 of the file | `<sha256 of the APK>` |
| Signing-key fingerprint (Settings → About) | `<SHA-256 fingerprint of the release key>` |

Install only from this page or the official Agent Setu WhatsApp group. A copy with a different fingerprint is not genuine.
