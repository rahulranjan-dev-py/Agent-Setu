## एजेंट सेतु (Agent Setu) 1.1.1 — पॉलिसी नंबर, PIN भूल गए, चेहरे से अनलॉक

**नया**
- **पूरा पॉलिसी / खाता नंबर (वैकल्पिक):** पॉलिसी के पेज पर लिखें; वहीं पूरा दिखता है, बाकी जगह केवल अंतिम 4 अंक। आधार, PAN या बैंक खाता नंबर के लिए नहीं।
- **PIN भूल गए?** PIN बनाते समय 8 अंकों का रिकवरी कोड एक बार दिखता है, उसे लिखकर रखें। PIN भूलने पर इस कोड से या अपने फ़ोन के लॉक (चेहरा, फ़िंगरप्रिंट, पैटर्न) से नया PIN रख सकते हैं। पुराने PIN वालों को कोड पाने के लिए एक बार PIN बदलना होगा (सेटिंग्स → ऐप लॉक)।
- **चेहरे से अनलॉक:** अब फ़िंगरप्रिंट, चेहरा या फ़ोन लॉक, जो भी आपके फ़ोन में हो।
- नया वर्शन मिलने पर "आज" स्क्रीन पर पॉप-अप।
- 1.1.0 के ऊपर सीधे इंस्टॉल करें; आपका डेटा बना रहेगा।

**इंस्टॉल कैसे करें**
1. नीचे **Assets** में `AgentSetu-v1.1.1.apk` डाउनलोड करें।
2. "अनजान ऐप इंस्टॉल करने" की अनुमति दें; Play Protect चेतावनी आए तो "Install anyway"।
3. ऐप में **सेटिंग्स → ऐप के बारे में** जाकर साइनिंग फ़िंगरप्रिंट नीचे दी गई फ़िंगरप्रिंट से मिलाएँ।

## Agent Setu 1.1.1 — policy numbers, Forgot PIN, face unlock

**New**
- **Full policy / account number (optional):** enter it on the policy's page; it is shown in full only there, and only the last 4 digits anywhere else. Not for Aadhaar, PAN or bank account numbers.
- **Forgot PIN?** When you set a PIN, an 8-digit recovery code is shown once; write it down. If you forget the PIN, that code or your phone's own lock (face, fingerprint, pattern) lets you set a new one. If you set your PIN before this version, change it once (Settings → App lock) to get a code.
- **Face unlock:** fingerprint, face or phone lock, whichever your phone has.
- A pop-up on Today when a new version is found.
- Install over 1.1.0; your data stays.

**Check your copy**

| | |
|---|---|
| File | `AgentSetu-v1.1.1.apk` |
| SHA-256 of the file | `<sha256 of the APK>` |
| Signing-key fingerprint (Settings → About) | `<SHA-256 fingerprint of the release key>` |

Install only from this page or the official Agent Setu WhatsApp group. A copy with a different fingerprint is not genuine.
