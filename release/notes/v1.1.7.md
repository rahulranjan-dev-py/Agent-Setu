## एजेंट सेतु (Agent Setu) 1.1.7 — कीबोर्ड सुधार, लेजर में छोड़ें/हटाएँ

**क्या बदला**
- कीबोर्ड खुलने पर स्क्रीन ऊपर खिसकती है, इसलिए जिस फ़ील्ड में टाइप कर रहे हैं वह अब छिपती नहीं (प्रोफ़ाइल, व्यवसाय जोड़ना, नियम जोड़ना, खोज, PIN)।
- लेजर: किसी प्रविष्टि पर टैप करके "छोड़ें: पात्र नहीं" चुन सकते हैं (रिकॉर्ड रहता है, कुल में नहीं गिनता, वापस भी कर सकते हैं) या उसे हटा सकते हैं।
- 1.1.6 के ऊपर सीधे इंस्टॉल करें (ऐप के अंदर "डाउनलोड" दबाएँ); आपका डेटा बना रहेगा।

**इंस्टॉल कैसे करें**
1. नीचे **Assets** में `AgentSetu-v1.1.7.apk` डाउनलोड करें।
2. "अनजान ऐप इंस्टॉल करने" की अनुमति दें; Play Protect चेतावनी आए तो "Install anyway"।
3. ऐप में **सेटिंग्स → ऐप के बारे में** जाकर साइनिंग फ़िंगरप्रिंट नीचे दी गई फ़िंगरप्रिंट से मिलाएँ।

## Agent Setu 1.1.7 — keyboard fix, skip or delete ledger entries

**What changed**
- When the keyboard opens, the screen moves up, so the field you are typing in is no longer hidden (profile, add business, add rule, search, PIN).
- Ledger: tap an entry and choose "Skip: not eligible" (kept for the record, not counted, reversible) or delete it.
- Install over 1.1.6 (tap Download inside the app); your data stays.

**Check your copy**

| | |
|---|---|
| File | `AgentSetu-v1.1.7.apk` |
| SHA-256 of the file | `<sha256 of the APK>` |
| Signing-key fingerprint (Settings → About) | `<SHA-256 fingerprint of the release key>` |

Install only from this page or the official Agent Setu WhatsApp group. A copy with a different fingerprint is not genuine.
