## एजेंट सेतु (Agent Setu) 1.0.1 — छोटा डाउनलोड

**क्या बदला**
- ऐप की फ़ाइल अब लगभग 22 MB से घटकर लगभग 7 MB है — WhatsApp पर भेजना और डाउनलोड करना तेज़।
- ऐप की सुविधाओं में कोई बदलाव नहीं। 1.0.0 के ऊपर सीधे इंस्टॉल करें; आपका डेटा बना रहेगा।

**इंस्टॉल कैसे करें**
1. नीचे **Assets** में `AgentSetu-v1.0.1.apk` डाउनलोड करें।
2. "अनजान ऐप इंस्टॉल करने" की अनुमति दें; Play Protect चेतावनी आए तो "Install anyway"।
3. ऐप में **सेटिंग्स → ऐप के बारे में** जाकर साइनिंग फ़िंगरप्रिंट नीचे दी गई फ़िंगरप्रिंट से मिलाएँ।

## Agent Setu 1.0.1 — smaller download

**What changed**
- The app file is now about 7 MB instead of about 22 MB, so it is quicker to download and to share on WhatsApp.
- No change to features. Install it over 1.0.0; your data stays.

**Check your copy**

| | |
|---|---|
| File | `AgentSetu-v1.0.1.apk` |
| SHA-256 of the file | `<sha256 of the APK>` |

Install only from this page or the official Agent Setu WhatsApp group. A copy with a different fingerprint is not genuine.
